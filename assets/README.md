# Assets

Photos and video for the README. **Currently empty — this is the biggest
cosmetic gap in the repository.**

Please drop files in here using these names so the README links work:

| File | What to shoot |
|---|---|
| `joint-hero.jpg` | the assembled joint, 3/4 angle, on a clean background. This is the image at the top of the README |
| `joint-assembled-1.jpg` … `-3.jpg` | assembled joint from other angles |
| `pcb-top.jpg` | bare or populated PCB, top side, macro |
| `pcb-bottom.jpg` | bottom side — `U2` and `U4` live here |
| `pcb-in-motor.jpg` | the board installed inside the motor bell, showing the radial phase pads |
| `gear-train.jpg` | the printed gears and rod laid out before assembly |
| `exploded.png` | an exploded view exported from `gearbox_assembly.SLDASM` |
| `demo.mp4` or `demo.gif` | **the joint running.** Keep a GIF under ~10 MB so it inlines on GitHub |
| `serial-monitor.png` | a capture of the `[POS]` / `[VEL]` / `[ENC]` output |

Tips:

- GitHub renders `.png`, `.jpg`, `.gif` inline in the README. `.mp4` and
  `.webm` only play when opened directly or dragged into an issue — so for a
  running demo, either attach the video to a GitHub issue and link it, or
  supply a GIF.
- A GIF over ~10 MB will not render inline in the README. Export at
  ≤ 800 px wide, 10–15 fps.
- If you have a video on Bilibili or YouTube, a link in the README is worth
  more than a large file in the repo.
